# Diamond High — Prototype Roadmap

This roadmap covers the first demonstrable e-school prototype only. See [Product Roadmap](PRODUCT_ROADMAP.md) for longer-term possibilities. This is directional, not a fixed schedule.

## Stage 0 — Recovery and baseline refinement
- [ ] Inventory and inspect repository and implementation.
- [ ] Reconcile historical school-site documents with the e-school identity.
- [ ] Confirm audiences, learner journey, and candidate modules.
- [ ] Review existing design references and establish Lunacy workspace.
- [ ] Define prototype content, learner journey, and completion criteria.
- [ ] Review technical and learning baseline.
- [ ] Obtain approval of consolidated baseline.

**Exit:** e-school identity, first learner journey, scope, design direction, and next milestone are clear and approved.

## Stage 1 — E-school landing page
Clarify communication goals and information architecture; learn and apply composition, hierarchy, typography, spacing, colour, and responsive design; design in Lunacy; review at meaningful milestones; implement only after baseline approval; test navigation, responsiveness, accessibility, and interactions.

**Exit:** landing page clearly introduces Diamond High as an e-school and guides learners into the prototype.

## Stage 2 — One integrated learning journey
Select one representative subject and objective; build a structured lesson and meaningful activity; provide explanatory feedback and review/retry; show an honest progress state and next step; test end to end.

**Exit:** reviewer can complete the learner journey and understand what is demonstrated.

## Stage 3 — Review and refinement
Gather feedback; separate observations from assumptions; evaluate learning activity against objectives; prioritise by learner value, effort, and risk; document capabilities and limitations.

## Stage 4 — Engineering improvement
Improve reusable components, testing, accessibility, performance, maintainability, and deployment when justified by requirements.

## Working rhythm
Agree on a small goal; inspect; learn relevant theory; let the creator apply it independently; review at meaningful checkpoints; test; record consequential decisions; and proceed when the result is understood. Prefer steady, demonstrable progress over rushed volume.
